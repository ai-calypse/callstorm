# README screenshots

- `callstorm-overview.png`: the review studio's result summary and overview.
- `callstorm-evidence.png`: speed and capacity evidence, including the
  relative-baseline verdict and the test-timing caveat.

These are browser captures of the local `/studio/` dashboard using the
repository's synthetic `graph-reference` test report. They illustrate the
interface, not a general performance claim about the provider.

To refresh them, run the dashboard, open `/studio/` at a desktop viewport,
select a synthetic report, and capture the overview. Then open **Explore
evidence**, select **Speed & capacity**, and capture the chart and takeaway.
Keep sample sizes and test-timing caveats visible. Never use customer calls
or private endpoints for public documentation images.
